# Orient Select Foods — Website

Static website for [Orient Select Foods](https://orientselectfoods.com), a US-based importer and wholesale distributor of premium frozen Asian foods.

## Pages

| File | Description |
|------|-------------|
| `index.html` | Entry point — redirects to homepage |
| `orient-select-foods-homepage.html` | Main landing page |
| `orient-select-foods-products.html` | B2B product catalog (3 SKUs) |
| `orient-select-foods-about.html` | About Us & Compliance |
| `orient-select-foods-partner.html` | Wholesale inquiry / contact |
| `orient-select-foods-admin.html` | Admin panel (login required) |

## Images

All product images are in the `images/` folder and referenced with relative paths.

## Deployment

Works on any static host: **GitHub Pages**, Netlify, Vercel, or plain web hosting.

### GitHub Pages setup
1. Push this folder to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to **main branch / root**
4. Your site will be live at `https://yourusername.github.io/your-repo/`
